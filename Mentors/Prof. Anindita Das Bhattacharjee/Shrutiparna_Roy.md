3. Class Tasks

https://drive.google.com/drive/folders/1Kj0aqGkORMauJNcQNyrOj87EOiHW8Gm1?usp=drive_link

This folder contains the framework implementations and class exercises. The subfolders included are:

Day 1 (Selenium Installation and Troubleshooting)
Installing and configuring Selenium with Python, verifying browser automation, and diagnosing common setup failures.

Day 2 (WebDriver Navigation, Checkbox Handling, Link Text Locators, and Form Automation)
Basic WebDriver navigation, checkbox handling with multi-browser support, link text locators, and complete form automation.

Day 3 (CSS Selectors, Wildcards, Link Collection, and Multiple Locator Strategies)
CSS parent-child selectors, wildcard attribute matching, collecting all links, and using multiple locator strategies.

Implementation of the Page Object Model design pattern for maintainable and reusable Selenium test code.

Robot Framework
